# Guide utilisateur

Ce document décrit les principales fonctions disponibles dans Mathom Notes 3.4.1.

## Organisation générale

Mathom Notes utilise la hiérarchie suivante :

- Mathom-House ;
- Étagère ;
- Page ;
- Mathom.

Une Mathom-House peut contenir des Étagères.

Une Mathom-House ou une Étagère peut contenir plusieurs Pages.

Les Pages contiennent les Mathoms.

## Créer une Mathom-House ou une Étagère

La commande **Nouveau** permet de créer un nouvel emplacement.

Lors de la création, l'utilisateur choisit notamment :

- son nom ;
- son icône ;
- son emplacement dans la hiérarchie.

Un emplacement créé à la racine est une Mathom-House.

Un emplacement créé dans une Mathom-House ou une Étagère est une Étagère.

## Mathoms

Mathom Notes prend notamment en charge :

- texte riche ;
- liens ;
- images ;
- fichiers ;
- lanceurs ;
- tableurs.

## Déplacement

Les Mathoms peuvent être déplacés par glisser-déposer.

Il est notamment possible de :

- modifier leur ordre ;
- les déplacer dans un groupe ;
- les sortir d'un groupe ;
- les déplacer vers une autre Page ;
- les déplacer vers une autre Étagère ou Mathom-House.

## Texte riche

L'éditeur de texte riche permet notamment :

- Gras ;
- Italique ;
- Souligné ;
- Exposant ;
- Indice ;
- couleur du texte ;
- police ;
- taille ;
- alignement à gauche ;
- centrage ;
- alignement à droite ;
- justification.

La sélection multiple permet d'appliquer certaines mises en forme à plusieurs zones sélectionnées.

## Annuler / Refaire

Mathom Notes dispose d'un historique global des modifications.

Les commandes **Annuler** et **Refaire** permettent de revenir sur les opérations prises en charge par cet historique.

L'ancien historique de navigation Précédent / Suivant a été supprimé en version 3.4.1.

## Tableur

Mathom Notes possède un type de Mathom tableur.

Il permet de saisir des valeurs et des formules.

Les commandes :

- `x²` ;
- `x₂`

permettent de convertir le texte sélectionné, ou le caractère précédent, vers des caractères Unicode en exposant ou en indice.

Les formules commençant par `=` ne sont pas modifiées par cette conversion.

## Pages

Les Pages permettent de disposer de plusieurs espaces de travail dans une même Mathom-House ou Étagère.

Elles peuvent être utilisées par exemple pour représenter :

- plusieurs chapitres ;
- plusieurs cours ;
- plusieurs parties d'un projet.

## Profils d'accessibilité

Le menu **Profil** permet d'activer des réglages adaptés à différents besoins.

Les profils peuvent être cumulés.

Mathom Notes propose notamment des profils pour :

- dyslexie ;
- dysorthographie ;
- dysphasie / TDL ;
- dyspraxie / TDC ;
- dyscalculie ;
- TDAH ;
- autres besoins ;
- profil personnalisé.

Selon le profil, Mathom peut notamment adapter :

- la police ;
- la taille ;
- les espacements ;
- la présentation ;
- certains outils de lecture et de repérage.

## Phonèmes et graphèmes

Mathom Notes intègre également des outils destinés au repérage phonème / graphème.

Ils font partie des fonctions d'accessibilité et d'aide à la lecture développées dans la série 3.x.

## Interface sur petit écran

Depuis Mathom Notes 3.4.1, la barre d'outils est organisée en priorité selon l'usage :

1. Nouveau / Annuler / Refaire ;
2. Gras / Italique / Souligné / Exposant / Indice / Couleur ;
3. Police / Taille ;
4. Alignements ;
5. Couper / Copier / Coller / Supprimer ;
6. fonctions secondaires.

Cette organisation vise notamment les écrans 14 pouces utilisés dans un contexte scolaire.
