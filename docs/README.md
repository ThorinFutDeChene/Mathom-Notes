## Documentation historique

Le dossier `doc/` provient du projet BasKet Note Pads.

Il contient notamment un ancien manuel KDE au format DocBook.

Ce contenu est conservé pour référence et pour certaines informations relatives au format historique `.baskets`, mais il ne constitue plus la documentation utilisateur de référence de Mathom Notes.
